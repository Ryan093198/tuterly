## Opportunities for Tuterly

1. **Own the VCE ATAR calculation explainer better than Apex owns WACE.** Our `/atar-planner` is a tool; we don't appear to have a plain-English "how VCE ATAR is calculated" explainer sitting alongside it. Apex's post is a template — we can do a more interactive Melbourne/VIC version tied directly to the planner.
2. **Consider a scoreboard of state ATAR guides.** If Apex is building WA, NSW, VIC guides, we could pre-empt with a definitive VCE/VIC one and cross-link to the planner as the working tool competitors don't have.
3. **Holiday program / seasonal landing pages.** North Shore's removed URLs reveal they build dedicated pages for each school-holiday intensive by state and term. We have `/tutoring` and city pages but no seasonal "VCE winter holiday intensive" style page. This is a repeatable, low-effort page pattern with clear seasonal intent.
4. **ACER / scholarship test events.** North Shore treats ACER prep as event-driven. Our `/scholarship-test-prep` is evergreen — adding upcoming-session or cohort-based framing could pick up parents searching close to test dates.
5. **Success Tutoring visibility gap.** If their site really is only 2 crawlable URLs, they're likely invisible to search. Worth a manual check — if confirmed, they're not a competitive threat in organic channels.
